## 6. 结果可靠性核验

1. **与官方统计逐项一致**：六局的清除数、检测次数、换频次数、空清除次数、虚拟时间与模拟器统计队列完全相同。
2. **时间账自洽**：用动作序列独立重算
   $T=\sum \|P_k-P_{k-1}\|/5+5N_{\text{检测}}+N_{\text{换频}}+5N_{\text{清除成功}}+3N_{\text{清除失败}}$
   与模拟器虚拟时间的差值不超过 $3\times10^{-6}$ s。
3. **证书闭合**：六局都是 20 个频道全部取得"已清除"或"认证不存在"的结论，没有未决频道；问题四三局的扫描点数均为 22，即连续域方向完备认证逐局通过。
4. **无冗余动作**：重复站位 0 次、同站同频道重复测量 0 次、被拒绝的动作 0 次。
5. **可复现**：用六份动作日志逐动作回放提交版本的代码，动作序列、坐标与频道与日志完全一致；上述源码哈希与日志首行记录一致。

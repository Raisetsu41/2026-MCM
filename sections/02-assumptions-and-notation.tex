\section{模型假设}

\subsection{假设说明}
题面给出的尺度、阈值与耗时按原口径直接使用见表~\ref{tab:common_conditions}，下列为模型建立所需的其他假设。
\begin{itemize}[itemindent=2em]
  \item \textbf{假设 1（静态平面框架）：}一次任务内源静止，检测点坐标已知无误差，忽略高度差。
  \item \textbf{假设 2（属性稳定）：}同频道有效观测对应同一源，接收半径与朝向一局内不变。
  \item \textbf{假设 3（确定性误差）：}示向误差仅满足区间界，不预设分布或独立性；同地重复检测误差固定，不取平均。
  \item \textbf{假设 4（理想传播）：}除题面接收距离与定向覆盖外，不引入遮挡、多径或源间干扰。
  \item \textbf{假设 5（理想运动）：}机器狗视为可即时转向、准确到达指令坐标的质点，只计直线移动与题面串行动作耗时。
\end{itemize}

\subsection{模型约定}
\begin{itemize}[itemindent=2em]
  \item \textbf{约定 1（异常与退化）：}约束交集为空表示观测不相容而非零面积；退化为单点或线段时，直径分别按零或线段长度定义。
  \item \textbf{约定 2（数值余量）：}数学推导取题面界 $\delta=1^\circ$；在线程序用 $1.01^\circ$ 包围示向度，仅吸收表示与量化误差，不改变物理模型。
  \item \textbf{约定 3（报告精度）：}认证区间与约束残差保留复核所需的原始精度，正文中的展示性位置、时间与距离通常保留两位小数。
\end{itemize}
